# 07. 실행 파일 (Unity 없이 실행)

Unity Hub나 에디터 없이 `JberryDrivingSim.exe` 하나로 시뮬레이터를 돌립니다. Windows 64비트만 지원합니다.

## 1. 팀원: 받아서 실행하기

1. `JberryDrivingSim_<날짜>.zip`을 원하는 폴더에 풉니다. 경로에 한글이 있어도 됩니다.
2. `JberryDrivingSim/JberryDrivingSim.exe`를 더블클릭합니다.
   - 처음 실행하면 Windows SmartScreen이 "알 수 없는 게시자"라고 막을 수 있습니다. **추가 정보 → 실행**을 누르세요.
3. 메인 메뉴 아래 상태 줄을 확인합니다.
   - **AI 엔진 준비됨**: 바로 리플레이 모드나 졸음 감지 시연을 시작하면 됩니다. 배포용 zip에는 휴대용 AI 엔진이 들어 있습니다.
   - **AI 엔진이 없습니다**: **[AI 엔진 설치]**를 누릅니다. 같은 폴더의 `AI_엔진_설치.bat`을 실행해도 됩니다. 인터넷이 필요하고 처음 한 번 수 분 걸립니다.

| 조작 | 키 |
|---|---|
| 창 모드 ↔ 전체 화면 | Alt + Enter |
| 세션 메뉴 (주행 계속 / 메인 메뉴 / 종료) | Esc |
| 그 밖의 조작키 | 주행 화면 오른쪽 아래 안내 |

### 폴더 구성

```
JberryDrivingSim/
├─ JberryDrivingSim.exe
├─ JberryDrivingSim_Data/StreamingAssets/Replays/   리플레이 기록 (팀 내부용 실측 기록 포함)
├─ Tools/jberry_ai/                                  AI 서버 (S1-EP + 상태 머신 v2)
│   └─ python/                                       휴대용 Python + torch(CPU) (배포 zip에 포함)
├─ SimLogs/                                          주행 로그·AI 판정 기록 (실행하면 생김)
├─ docs/                                             이 설명서
├─ AI_엔진_설치.bat
└─ 읽어보기.txt
```

- 새 기록을 넣으려면 `Tools/convert_recording.py`로 변환한 폴더(`meta.json`, `ecg.csv`, `ppg.csv`)를 `JberryDrivingSim_Data/StreamingAssets/Replays/`에 넣고 메인 메뉴에서 **목록 새로고침**을 누릅니다.
- 실측 모드(UDP 수신)를 쓰면 Windows 방화벽이 처음에 허용 여부를 묻습니다. **개인 네트워크 허용**을 고르세요.

### AI 엔진 설치는 이렇게 진행됩니다 (`Tools/jberry_ai/setup_ai.ps1`)

1. PC에 Python 3.10~3.13이 있으면 `Tools/jberry_ai/.venv`를 만들어 패키지를 설치합니다.
2. 없으면 python.org의 공식 휴대용 Python(embeddable zip)을 `Tools/jberry_ai/python`에 내려받아 그 안에 설치합니다. PC에는 아무것도 설치하지 않습니다.
3. 패키지는 numpy·scipy·pandas·scikit-learn·pyyaml·safetensors·torch(CPU)입니다. 마지막으로 모델을 한 번 돌려 봅니다.
4. 진행 상황은 `SimLogs/ai/setup_status.txt`에, 전체 출력은 `SimLogs/ai/setup_log.txt`에 남습니다.

AI 서버는 `Tools/jberry_ai/python/python.exe`를 먼저 찾고, 없으면 `.venv`를 씁니다.

## 2. 개발자: 실행 파일 만들기

Unity 에디터에서 메뉴로 만듭니다.

| 메뉴 | 하는 일 |
|---|---|
| **Capstone > 실행 파일 빌드 (Windows)** | `Build/JberryDrivingSim/`에 실행 파일을 만들고 `Tools`·`docs`를 옆에 복사 |
| **Capstone > 배포용 빌드 (휴대용 AI 엔진 + zip)** | 위 빌드 → 빌드 폴더 안에 휴대용 AI 엔진 설치 → `Build/JberryDrivingSim_<날짜>.zip` |
| **Capstone > 배포 zip 만들기** | 이미 만든 빌드 폴더만 zip으로 |

- 다시 빌드해도 빌드 폴더에 설치한 AI 엔진(`python/`, `.venv/`)은 그대로 둡니다.
- zip에서 빼는 것: `SimLogs/`(개인 주행 기록), `.venv/`(다른 PC로 옮기면 동작하지 않음), `__pycache__`, Unity 디버그 폴더(`*_DoNotShip`).
- 빌드 때 `Assets/CapstoneSim/Resources/ShaderKeep/`에 재질 48개를 만듭니다. 코드에서 `Shader.Find`로 만드는 URP Lit 재질이 빌드에서 빠지지 않게 하려는 것으로, 저장소에는 올리지 않습니다(`.gitignore`).
- 빌드 설정: 제품 이름 `J_Berry Driving Sim`, 전체 화면 창 모드, 창 크기 조절 가능, **Run In Background 켜짐**(창이 뒤에 있어도 생체 재생과 AI 통신이 계속됨).

### 자동으로 돌리기 (`SimLogs/autotest/build_request.txt`)

```
build=1                 # 실행 파일 빌드
setup=portable          # 빌드 폴더에 휴대용 AI 엔진 설치 (system = PC의 Python으로 .venv)
test=bx01_exe           # 빌드한 exe를 자동 테스트 모드로 실행 → Build/JberryDrivingSim/SimLogs/autotest/bx01_exe/
t.duration=50           # t.<키> = 자동 테스트 인자 (05_자동테스트.md의 request.txt 키와 같음)
t.replay=rec_20261118
t.baseline=rec_20261118_baseline
t.bio_offset=960
t.ai_preroll=1
pack=1                  # zip 만들기
```

진행 상황은 `SimLogs/autotest/build_status.txt`에 남습니다. 에디터가 백그라운드에 있으면 멈추므로 Unity 창을 앞에 띄워 두세요.

## 3. 주의

- 배포용 zip에는 **실측 생체 기록**(`rec_20261118`, 기준 파일)이 들어 있습니다. 팀 안에서만 공유하세요.
- 모델 가중치는 WESAD로 학습해 **비상업적 용도로만** 쓸 수 있습니다.
- 차량 모델(에셋 스토어)은 빌드 안에 컴파일된 형태로만 들어갑니다. 원본 에셋 파일은 zip에 없습니다.
