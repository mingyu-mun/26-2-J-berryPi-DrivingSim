# 05. 자동 테스트 (재컴파일 → Play → 스크린샷 → 리포트)

에디터를 열어 둔 상태에서 `SimLogs/autotest/request.txt`를 쓰면 `Editor/SimAutoTester.cs`가 1초마다 이를 확인하고 아래 과정을 알아서 진행합니다. 메뉴 **Capstone > 자동 테스트 실행**으로 바로 돌릴 수도 있습니다.

1. (`refresh=true`이면) 에셋을 새로고침하고 다시 컴파일합니다. 결과는 `compile_status.txt`에 남고, 에러가 있으면 여기서 멈춥니다.
2. `set.<필드>=<값>`이 있으면 `DrivingSim` Inspector 값을 바꾸고 씬을 저장합니다. 결과는 `settings_applied.txt`에 남습니다.
3. Play를 시작하면 `AutoTestRunner`가 자율주행(Stanley 조향 + 속도 유지)으로 차를 몹니다.
4. 스크린샷을 찍습니다: 차량 외관 4장, 운전석·추적 시점, 곡선, 조감, 그리고 HUD가 포함된 Game 뷰를 10초마다.
5. `report.txt`를 남기고 Play를 종료합니다. 리포트에는 FPS, 바퀴 정렬, 차선 편차, **AI 판정 흐름(1초마다)**, 서버 출력, 콘솔 에러가 들어 있습니다.

## request.txt

```
id=ai11_drowsy        # 결과 폴더 이름 (SimLogs/autotest/<id>/)
refresh=false         # 스크립트를 바꿨으면 true
duration=110          # Play 길이 [s]
speed=90              # 자율주행 속도 [km/h]
bio_offset=960        # Replay 시작 위치 [s]
ai_mode=causal        # causal / exact
ai_preroll=1          # 시작 위치 앞 기록을 미리 빠르게 넣기
set.night=true        # (선택) Inspector 값 변경 + 씬 저장
menu=home             # (선택) 세션을 시작하지 않고 메인 메뉴의 home / replay / live 화면에 머묾 (메뉴 스크린샷)
replay=rec_20261118   # (선택) 리플레이 기록 이름
baseline=rec_20261118_baseline   # (선택) 기준 측정 파일 이름, auto = 자동 수집
pause_at=40           # (선택) 그 시각에 세션 메뉴(Esc 화면)를 띄움
```

`menu` 키가 없으면 메뉴를 건너뛰고 Inspector 값과 위 인자로 리플레이 세션을 바로 시작합니다.

## 현재 상태 확인

- `SimLogs/autotest/status.txt`: `idle`, `refreshing (<id>)`, `playing (<id>)`, `done`, `failed (<id>): 이유` 중 하나
- 누군가 에디터에서 직접 Play 중이면 요청은 Play가 끝난 뒤에 처리됩니다.
