# 01. 설치

대상: Windows 10/11 x64. 마지막 확인: 2026-11-18, Unity 6000.6.9f1, Python 3.13.

## 1. Unity

1. https://unity.com/download 에서 **Unity Hub**를 설치하고 로그인한 뒤, 무료 **Personal** 라이선스를 활성화합니다.
2. Hub → **Installs → Install Editor**에서 **6000.6.9f1**을 설치합니다.
   - 버전이 정확히 같아야 합니다. `ProjectSettings/ProjectVersion.txt`에 적혀 있습니다. 목록에 없으면 *Archive* 탭이나 Unity 다운로드 아카이브에서 찾습니다.
   - 모듈은 *Microsoft Visual Studio Community*(또는 VS Code + C# Dev Kit)만 있으면 충분합니다. 실행 파일(.exe)로 빌드하려면 *Windows Build Support (IL2CPP)*도 설치합니다.
3. 저장소를 **영문 경로**에 클론합니다. 경로에 한글이나 공백이 있으면 패키지 빌드 오류가 날 수 있습니다.
   ```bash
   git clone https://github.com/mingyu-mun/26-2-J-berryPi-DrivingSim.git C:/Unity/JBerrySim
   ```
4. Hub → **Projects → Add → Add project from disk**에서 클론한 폴더를 선택해 엽니다. 처음 열 때는 패키지 받기와 `Library/` 생성 때문에 수 분 걸립니다.
5. Console 창(Ctrl+Shift+C)에 **빨간 에러가 없고**, 상단 메뉴에 **Capstone**이 보이면 성공입니다.
6. `Edit > Project Settings > Player > Active Input Handling`이 **Both**나 **Input System Package (New)**인지 확인합니다. 저장소 설정은 이미 맞춰져 있습니다.

> 이 프로젝트는 *Enter Play Mode Options*에서 도메인 리로드를 꺼 두었습니다. 그래서 Play를 누르면 바로 시작합니다. 코드에 static 값을 추가할 때는 `RuntimeInitializeOnLoadMethod(SubsystemRegistration)`에서 초기화해야 합니다.

## 2. 차량 에셋 (선택)

에셋이 없어도 코드로 만든 기본 차량으로 동작합니다. 씬에는 **Sport Car Free** 프리팹이 연결되어 있습니다. 같은 모양으로 쓰려면 다음과 같이 합니다.

1. Unity Asset Store에서 *Sport Car Free*를 계정에 추가합니다 (무료).
2. `Window > Package Manager > My Assets` → *Sport Car Free* → Download → Import를 차례로 진행합니다. `Assets/SportCar/`에 들어갑니다.
3. 씬을 다시 엽니다. 에셋의 GUID가 같으므로 `DrivingSim`의 *Car Model Prefab*(SportCar_1)과 *Model Wheel Prefab*(Sport_Wheel_1)이 저절로 연결됩니다. 연결되지 않으면 Inspector에 직접 끌어다 놓습니다.
   - *Model Wheel Names*는 `FL, FR, RL, RR`로 이미 설정되어 있습니다.
   - Built-in / HDRP 머티리얼은 Play할 때 자동으로 URP로 바뀝니다 (`MaterialFixer`).

에셋 스토어 에셋은 **저장소에 커밋하지 않습니다**. 재배포가 금지되어 있으며, 해당 경로는 `.gitignore`에 들어 있습니다.

## 3. AI 추론 환경 (Python)

1. **Python 3.10~3.13**을 설치합니다. 3.12를 권장합니다.
   - torch가 아직 지원하지 않으므로 3.14만 있으면 안 됩니다. 3.14와 함께 설치해 두는 것은 괜찮습니다. 설치 스크립트가 `py -3.12 / -3.11 / -3.13 / -3.10` 순서로 찾습니다.
   - python.org 설치 프로그램에서 *Add python.exe to PATH*를 체크하거나, *py launcher*가 함께 설치되는지 확인합니다.
2. Unity 메뉴에서 **Capstone > AI 추론 환경 설치 (Python venv)**를 실행합니다. 백그라운드에서 다음 작업이 진행됩니다.
   - `Tools/jberry_ai/.venv` 생성
   - `numpy scipy pandas scikit-learn pyyaml safetensors` + `torch`(CPU 판, https://download.pytorch.org/whl/cpu) 설치
   - `selftest.py` 실행: 저장소 모델을 불러와 실측 기록(없으면 합성 파형 10분)으로 실제 추론
3. 결과를 확인합니다.
   - `SimLogs/ai/setup_status.txt`: `ok`면 끝입니다. `fail: …`이면 원인이 적혀 있습니다.
   - `SimLogs/ai/setup_log.txt`: 전체 출력
   - 내려받기 크기는 약 300 MB, 소요 시간은 2~5분입니다.

수동 설치 (메뉴를 쓸 수 없을 때):

```bat
cd Tools\jberry_ai
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python selftest.py
```

## 4. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `Capstone` 메뉴가 안 보임 | 컴파일 에러부터 해결합니다 (Console). `Assets/CapstoneSim/Editor` 폴더가 있는지 확인합니다. |
| 도로·차량이 분홍색 | URP 설정이 빠졌습니다. `Assets/Settings/PC_RPAsset`이 `Project Settings > Graphics`에 지정되어 있는지 확인합니다. |
| AI 패널: "AI 추론 환경 미설치" | 3절 메뉴를 실행합니다. |
| AI 패널: "AI 서버 실행 실패" | `SimLogs/ai/server_stdout.txt`를 확인합니다. 패키지 누락이면 3절을 다시 실행합니다. |
| AI 패널: "UDP 포트 열기 실패" | 다른 프로그램이 5006 포트를 쓰고 있습니다. 이전 Play의 서버가 남아 있으면 작업 관리자에서 python을 종료합니다. |
| 파형 패널: "생체 기록 없음" | `SimLogs/bio/rec_20261118`이 없습니다. [02_구동절차 1절](02_구동절차.md#1-replay-데이터-준비)을 따릅니다. |
| Windows 방화벽 경고 | 통신은 127.0.0.1(로컬) UDP만 씁니다. *개인 네트워크* 허용으로 충분합니다. |
| 외부 차량 바퀴가 안 돎 / 엉뚱한 부품이 돎 | Console의 `[CarModel]` 로그를 확인한 뒤 *Model Wheel Names*에 바퀴 오브젝트 이름을 직접 입력합니다. |
